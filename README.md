# hyprnotes · downloads

Versões compiladas do **hyprnotes**: notas rápidas com a velocidade de um chat, e por trás um caderno com Markdown, LaTeX, PDF e quadro infinito.

Baixe na aba [Releases](https://github.com/imeliot/hyprnotes-releases/releases):

- **Linux (x86_64):** `hyprnotes-x86_64.AppImage`. Depois de baixar, `chmod +x hyprnotes-x86_64.AppImage` e abra.
- **Android 7+:** `hyprnotes.apk`. Libere "instalar apps desconhecidos" pro navegador.

Links diretos pra versão mais nova:

- https://github.com/imeliot/hyprnotes-releases/releases/latest/download/hyprnotes-x86_64.AppImage
- https://github.com/imeliot/hyprnotes-releases/releases/latest/download/hyprnotes.apk

Ainda é alfa: faça backup das suas notas. O código-fonte do app não fica neste repositório.
